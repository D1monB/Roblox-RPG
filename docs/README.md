# Дизайн-документи гри

Цей каталог описує механіки гри. Claude Code читає його перед реалізацією будь-якої системи.
Правила розробки та безпеки лежать у `CLAUDE.md` у корені репозиторію.

## Як користуватися
- Один файл на одну систему.
- Кожен файл має розділи: **Референс**, **Що беремо**, **Що міняємо**, **Числа**, **Roblox і безпека**, **Відкриті питання**.
- Числа позначені `ПЛЕЙСХОЛДЕР`: це стартові значення для налаштування, не фінальний баланс.
- Назви, лор, тексти й графіка чужих ігор НЕ копіюються. Беремо лише правила механік.

## Журнал рішень
Ухвалені рішення (платформи, вибір цілі, респек, лут, смерть, сетинг, ресурси) лежать у `decisions.md`.
Якщо документ системи суперечить журналу, діє журнал.

## Пізніше (не в першій версії)
- Квести й діалоги (BG3/Divinity): описуються даними, не кодом.
- Взаємодія стихій (Divinity): у v1 лише закладаємо поле типу урону та систему ефектів стану в `combat.md`.
- Боси й данжі (референс ще не вибраний, кандидат: групові енкаунтери WoW).
