# Game Design Document (GDD): Roblox RPG

> Живий документ. Заповнюємо разом, крок за кроком. Код пишемо тільки після того, як розділ має відповідь.
> Як заповнювати: у кожному питанні постав `[x]` біля свого варіанта або впиши свій у «Свій варіант».
> ⭐ = рекомендація (найпростіше зробити безпечно й швидко). Обирати її не обов'язково.

## 0. Що вже вирішено (з CLAUDE.md)

- **Жанр:** мультиплеєрна RPG. Острови, підземелля, боси.
- **Режими:** соло і кооп працюють на одній серверній моделі (сервер вирішує все).
- **Розподіл роботи:** код пише розробник (з Claude). Модельки, карту й дизайн робить друг (Blender → Studio).
  Карта в репозиторії не редагується: код лише «знаходить» об'єкти карти за домовленими шляхами й тегами (див. розділ 9).
- **Безпека понад усе:** клієнт надсилає лише намір («вдарити ціль X»), сервер перевіряє й рахує результат.
- **Фічі коду:** `profile`, `stats`, `combat`, `abilities`, `inventory`, `enemies`, пізніше `dungeons`, `world`.

## 2. Бойова система

**2.1 Стиль бою**
- [ ] ⭐ Екшн без таргету: клік = удар у напрямку, клавіші 1–4 = здібності з кулдауном. Серверу легко перевіряти дальність і кулдаун.
- [ ] Комбо-бій: ланцюжки ударів, блок, ухилення, парирування. Найцікавіше, найскладніше чесно зробити при пінгу.
- [ ] Таб-таргет (MMO): обираєш ціль, здібності б'ють автоматично. Найпростіше.

**2.2 Типи атак у MVP** (можна кілька)
- [ ] Ближній бій (меч)
- [ ] Дальній бій (лук / снаряди)
- [ ] Магія по площі (AoE)

**2.3 Смерть гравця**
- [ ] ⭐ Респавн у найближчому чекпоінті, без втрати предметів.
- [ ] Респавн + штраф (втрата частини золота / XP).
- [ ] Хардкор (втрата предметів). Не рекомендую для Roblox-аудиторії.

**2.4 PvP**
- [ ] ⭐ Немає (тільки PvE) у першій версії.
- [ ] Лише на арені / дуелі за згодою.
- [ ] Відкритий PvP у певних зонах.

## 3. Класи і прогресія

**3.1 Модель розвитку**
- [ ] ⭐ Класи + рівні: на старті вибір класу, рівні дають очки характеристик.
- [ ] Без класів: здібності залежать від зброї.
- [ ] Рівні + дерево талантів.

**3.2 Класи на старті** (якщо обрано класи)
- [ ] Воїн

- Свої:

## 4. Предмети та економіка

**4.1 Валюта**
- [ ] ⭐ Одна валюта (золото), здобувається тільки в грі.
- [ ] Дві валюти: золото + преміум (купується за Robux).

**4.2 Лут**
- [ ] ⭐ Рідкісності: Звичайний / Рідкісний / Епічний / Легендарний, таблиці луту на кожного ворога.
- [ ] Лише фіксовані нагороди за квести.

**4.3 Інвентар**
- [ ] ⭐ Сітка з обмеженням слотів + екіпірування (зброя, броня, аксесуар).
- [ ] Без обмежень.

**4.4 Обмін між гравцями**
- [ ] ⭐ Немає в MVP (найбільше ризиків дюпу предметів).
- [ ] Прямий обмін з підтвердженням обох сторін (атомарна операція на сервері).
- [ ] Аукціон / торговець.

**4.5 Крафт**
- [ ] Немає в MVP
- [ ] Простий: N ресурсів → предмет.

**4.6 Монетизація (Robux)**
- [ ] ⭐ Лише косметика та зручності (слоти інвентаря, ще один персонаж). Без «купи силу».
- [ ] Бусти XP / золота.
- [ ] Поки без монетизації.

## 9. Контракт «карта ↔ код» (домовленість з другом)

Щоб друг міг вільно міняти карту, а код не ламався, код шукає об'єкти лише за **тегами** (`CollectionService`) і **атрибутами**:

| Тег | Що це | Атрибути |
|-----|-------|----------|
| `EnemySpawn` | точка появи ворога | `enemyId` (string), `respawnSeconds` (number) |
| `PlayerSpawn` | точка відродження | `zoneId` |
| `ZoneTrigger` | межа зони | `zoneId`, `minLevel` |
| `DungeonEntrance` | вхід у підземелля | `dungeonId` |
| `Npc` | торговець / квестодавець | `npcId` |

## 10. Порядок розробки (пропозиція)
