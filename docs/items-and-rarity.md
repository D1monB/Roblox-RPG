# Предмети, спорядження та рідкість

## Референс
Baldur's Gate 3 / Divinity: спорядження в слотах, рівні рідкості предметів, що впливають на силу та кількість бонусів.

## Що беремо
- Спорядження в слотах: зброя, шолом, броня, штани, взуття, прикраса.
- Рівні рідкості предметів: `common`, `uncommon`, `rare`, `epic`, `legendary`.
- Чим вища рідкість, тим більше бонусів і вища сила предмета.
- Предмет це **дані**: ID, назва, слот, рідкість, бонуси, вимога рівня.

## Що міняємо
- У v1 немає складних вимог до статів для екіпірування, лише мінімальний рівень.
- Без крафту та покращення предметів (пізніше).

## Числа (ПЛЕЙСХОЛДЕР)
- Кількість бонусів: common 0, uncommon 1, rare 2, epic 3, legendary 4.
- Розмір інвентаря: 30 слотів.
- Розмір стеку для витратних предметів: 20.
- Шанси дропу від ворога: common 70%, uncommon 20%, rare 8%, epic 1.8%, legendary 0.2%.

## Roblox і безпека
- Інвентар і спорядження змінює **лише сервер**. Клієнт надсилає наміри («екіпірувати предмет у слот N»).
- Сервер перевіряє: предмет у гравця, слот підходить, вимога рівня виконана, індекс слота в межах.
- Операції, що переміщують цінність (підбір, випадіння, обмін, купівля), атомарні, щоб унеможливити дублювання.
- У профілі зберігаємо ID предмета й кількість; параметри предмета беруться з даних при завантаженні.
- Лут генерується на сервері; клієнт ніколи не повідомляє, що випало.
- Невідомий ID предмета в старому збереженні не має ламати завантаження профілю.

## Тести
- Екіпірування: неправильний слот, предмета немає, не вистачає рівня.
- Атомарність: повторне натискання «підібрати» не дає двох предметів.
- Розподіл лута відповідає шансам на великій вибірці (статистична перевірка з допуском).
- Профіль із невідомим ID предмета завантажується без помилки.
