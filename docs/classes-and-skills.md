# Класи й навички

## Референс
Baldur's Gate 3 / Divinity: класи з власними навичками, відкриття здібностей через прогрес і вибір гравця.

## Що беремо
- Клас визначає стартові статі та набір доступних здібностей.
- Здібності відкриваються з рівнем і вибором у дереві навичок.
- Навички описані як **дані**: назва, тип, вартість, кулдаун, коефіцієнти урону, вимоги.

## Що міняємо
- Без покрокового бою (він із цих ігор не підходить для мультиплеєра).
- У v1 лише 3 класи й невелике дерево.

## Класи v1
| Клас | Стиль | Основні статі |
|---|---|---|
| Воїн | ближній бій | strength, vitality |
| Маг | магія на відстані | intelligence, mind |
| Лучник | фізика на відстані | dexterity |

Клас обирається на початку. Назви й ідентифікатори (`warrior`, `mage`, `archer`) це стабільні ID, їх не змінюємо після релізу.

## Дерево навичок (ПЛЕЙСХОЛДЕР)
- 6 здібностей на клас у v1: 2 стартові + 4, що відкриваються з рівнем.
- Очко навички за кожен 2-й рівень (окремо від очок статів).
- Кожна здібність має вимогу: мінімальний рівень і, за потреби, попередня здібність.

## Roblox і безпека
- Відкриття навички це запит від клієнта; сервер перевіряє рівень, очки навичок і вимоги.
- У профілі зберігаємо ID відкритих здібностей, а не їхні параметри (параметри беруться з даних при завантаженні).
- Дані здібностей лежать у `shared/features/abilities/definitions/`, один формат на всі класи.

## Тести
- Відкриття навички: без очок, без виконаних вимог, повторне відкриття.
- Профіль із ID здібності, якої вже немає в даних (після оновлення): гра не падає.

## Відкриті питання
- ~~Зміна класу або мультиклас?~~ Вирішено: клас вибирається один раз і не змінюється (`decisions.md`, #4).
- ~~Скидання навичок?~~ Вирішено: респек за ігрове золото. Ціна ще не задана.
